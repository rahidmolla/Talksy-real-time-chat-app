# 💬 Talksy — Real-Time Chat Application

Talksy is a real-time chat application built to learn and implement real-time communication using **Node.js, Express.js, Socket.IO, HTML, CSS, and JavaScript**.

The main goal of this project is to understand how a client and server communicate instantly using Socket.IO.

---

## 🚀 Features

- 💬 Real-time messaging
- 👤 Username-based chat
- 🟢 User join notifications
- 🔴 User leave notifications
- 🔊 Message notification sound
- ⚡ Real-time communication using Socket.IO
- 🎨 Dark-themed chat interface
- 📱 Simple and responsive UI

---

## 🛠️ Tech Stack

### Frontend

- HTML5
- CSS3
- JavaScript

### Backend

- Node.js
- Express.js
- Socket.IO
